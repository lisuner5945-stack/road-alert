# Pipeline базы камер (OpenStreetMap → приложение)

Собирает `camera_database.json.gz`, `metadata.json` и `SHA256SUMS`
из открытых данных OpenStreetMap. Бесплатно, без собственного сервера:
запускается в GitHub Actions раз в сутки.

## Файлы

| Файл | Назначение |
|---|---|
| `regions.py` | разбиение РФ на прямоугольники для вежливых запросов |
| `overpass.py` | клиент Overpass API: retry, backoff, перебор инстансов |
| `normalize.py` | OSM-теги → схема приложения, парсинг maxspeed/direction |
| `validate.py` | проверки, без которых база не публикуется |
| `build_database.py` | точка входа: сборка, валидация, запись файлов |
| `test_pipeline.py` | тесты; в CI выполняются ДО обращения к сети |
| `sample_elements.json` | локальные данные для `--sample` |

## Локальный запуск

```bash
python -m unittest discover -p "test_*.py"     # тесты
python build_database.py --output out --sample # без сети
python build_database.py --output ../../database # реальная сборка (долго)
```

## Правила безопасности публикации

Новая база НЕ публикуется, если:

- камер получилось ноль;
- файл не парсится или не проходит перечитывание после упаковки;
- есть невалидные координаты, дубликаты id или неправдоподобные ограничения;
- количество камер упало более чем на 40% относительно предыдущей версии
  (обходится вручную: `--allow-shrink`).

При сбое источника предыдущая рабочая база остаётся на месте.

## Вежливость к Overpass

Публичные инстансы Overpass бесплатны и часто перегружены, поэтому pipeline:

- запрашивает данные регион за регионом, а не одним огромным запросом;
- делает паузу 15 секунд между регионами;
- при ошибке повторяет попытку с экспоненциальной задержкой (20 → 40 → 80 с);
- по кругу перебирает несколько инстансов;
- представляется в User-Agent.

## Схема данных

```json
{
  "schema_version": 1,
  "database_version": "2026-08-18T01:23:00Z",
  "generated_at": "2026-08-18T01:23:00Z",
  "source": "OpenStreetMap",
  "license": "ODbL",
  "cameras": [
    {"id": "osm:node:1001", "lat": 55.751244, "lon": 37.618423,
     "type": "SPEED_CAMERA", "speed_limit": 60, "direction": 180.0,
     "osm_type": "node", "osm_id": 1001}
  ]
}
```

`metadata.json` содержит `sha256` **упакованного** файла — именно его проверяет
приложение перед импортом.
