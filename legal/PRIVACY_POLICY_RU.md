## 1. Коротко

Приложение предупреждает водителя о камерах контроля скорости, сравнивая
координаты GPS с базой камер, которая хранится **на самом устройстве**.

- Маршруты и история поездок **не передаются** разработчику.
- У приложения **нет** аккаунтов, регистрации и пользовательского сервера.
- Точная геолокация **не передаётся** рекламному SDK кодом приложения.
- Карта камер использует подложку OpenStreetMap; серверам карты видна
  только примерная область просмотра (см. п. 2.4).
- Обработка координат выполняется **локально**, во время активной поездки.

## 2. Какие данные обрабатываются

### 2.1. Геолокация (точная)

**Зачем:** чтобы определить расстояние до камеры впереди по ходу движения,
текущую скорость и направление движения. Без точных координат функция
предупреждения невозможна.

**Когда:** только во время активной поездки, которую пользователь запускает
сам кнопкой «Начать поездку» (или подтверждает одним нажатием при подключении
к выбранному автомобилю).

**Где обрабатывается:** локально на устройстве. Координаты используются
в оперативной памяти для расчёта расстояний и не отправляются разработчику.

**Хранение:** постоянный GPS-трек не сохраняется. В отладочной сборке возможен
ограниченный локальный технический журнал; в публикуемой сборке точный
GPS-трек не сохраняется.

### 2.2. Настройки приложения

Локально хранятся: включён ли голос, звук, вибрация, допуск превышения,
профиль дистанций, позиция overlay, выбранное Bluetooth-устройство автомобиля,
версия базы камер и время последней проверки обновления. Эти данные не покидают
устройство (кроме случая, когда пользователь сам включил системное резервное
копирование Android).

### 2.3. Обновление базы камер

Приложение периодически (не чаще раза в сутки, только при наличии сети)
скачивает файл базы камер по HTTPS с публичного хранилища. При этом
передаются только технические данные, неизбежные при HTTP-запросе
(IP-адрес, версия приложения в User-Agent). Геолокация в этом запросе
не участвует.

### 2.4. Карта камер

На экране «Карта камер» приложение показывает подложку OpenStreetMap.
Изображения карты (тайлы) загружаются по HTTPS с публичных серверов
OpenStreetMap. Вместе с запросом тайла серверу становится известен
**номер квадрата карты**, который пользователь сейчас рассматривает,
то есть примерная область просмотра — но не траектория движения
и не точные координаты устройства.

- Карта открывается только вручную и не используется во время поездки.
- Синяя точка «где я» рисуется **на самом устройстве**; координаты
  при этом никуда не отправляются.
- Загруженные тайлы кэшируются во внутреннем кэше приложения
  (не более 60 МБ) и удаляются вместе с приложением.
- Правила использования тайлов OSM:
  https://operations.osmfoundation.org/policies/tiles/

### 2.5. Реклама (Yandex Mobile Ads)

Приложение может показывать рекламу с помощью Yandex Mobile Ads SDK.

- Рекламный SDK может самостоятельно обрабатывать технические
  и рекламные идентификаторы в соответствии с правилами Яндекса.
- Приложение **не передаёт** SDK точные GPS-координаты пользователя;
  отслеживание местоположения в SDK выключено явно.
- Полноэкранная реклама **никогда** не показывается во время активной поездки.
- Правила Яндекса: https://yandex.ru/legal/confidential/

### 2.6. Что не собирается

Приложение не запрашивает и не обрабатывает: контакты, SMS, журнал звонков,
микрофон, камеру, фотографии, IMEI, номер телефона, платёжные данные.
Аккаунтов и авторизации в приложении нет.

## 3. Источник данных о камерах

Данные о камерах и подложка карты основаны на OpenStreetMap
и распространяются по лицензии ODbL:

```
© OpenStreetMap contributors
```

База не является полной: приложение — вспомогательное средство и не заменяет
внимание водителя и соблюдение ПДД.

## 4. Передача третьим лицам

Разработчик не продаёт и не передаёт персональные данные третьим лицам.
Единственный сторонний компонент, обрабатывающий данные, — рекламный SDK
Яндекса (см. п. 2.5).

## 5. Разрешения Android

| Разрешение | Зачем | Когда запрашивается |
|---|---|---|
| `ACCESS_FINE_LOCATION` | расстояние до камер, скорость, направление | при первом запуске поездки |
| `ACCESS_COARSE_LOCATION` | резервный источник координат | вместе с предыдущим |
| `FOREGROUND_SERVICE_LOCATION` | работа при выключенном экране | при запуске поездки |
| `POST_NOTIFICATIONS` | уведомление активной поездки | при запуске поездки |
| `BLUETOOTH_CONNECT` | распознать подключение к выбранному автомобилю | только при включении автозапуска |
| `SYSTEM_ALERT_WINDOW` | карточка предупреждения поверх навигатора | только при включении overlay |
| `INTERNET`, `ACCESS_NETWORK_STATE` | обновление базы камер, подложка карты, реклама | без отдельного диалога |

Фоновая геолокация (`ACCESS_BACKGROUND_LOCATION`) **не запрашивается**.

## 6. Как остановить обработку данных

- Нажать «Стоп» — поездка завершается, определение координат прекращается.
- Отозвать разрешение на геолокацию в настройках Android.
- Выключить автообновление базы в настройках приложения.
- Удалить приложение — все локальные данные удаляются вместе с ним.
