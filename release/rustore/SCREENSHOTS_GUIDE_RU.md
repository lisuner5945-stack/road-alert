# Как снять скриншоты для RuStore

Требования RuStore: минимум 3 скриншота, до 10, PNG/JPG, рекомендуется 16:9,
максимум 2160×3840 для телефона, файл ≤ 3 МБ. Только реальные экраны приложения,
без сторонней рекламы в кадре и без функций, которых нет.

## Подготовка

1. Установить debug-сборку:
   ```bash
   ./gradlew installDebug
   ```
2. Включить в настройках то, что будете показывать (HUD, overlay).
3. Выключить панель уведомлений с личными данными, поставить нейтральное время.

## Кадры

| # | Экран | Как получить |
|---|---|---|
| 1 | Главный до поездки | Открыть приложение после загрузки базы (статус «актуальна») |
| 2 | Активная поездка с камерой впереди | Developer tools → «Replay test route» → «Fake camera ahead» |
| 3 | HUD | В поездке нажать «HUD» |
| 4 | Настройки | Главный экран → «Настройки» |
| 5 | О данных (атрибуция OSM) | Главный экран → «О данных» |

Overlay снимать только если в кадре нет интерфейса стороннего приложения.

## Снятие

```bash
adb shell screencap -p /sdcard/shot1.png
adb pull /sdcard/shot1.png
```

## Проверка перед загрузкой

- [ ] На кадрах нет рекламы (в debug баннер использует demo-блоки Яндекса —
      такие кадры загружать нельзя, снимайте экраны без баннера или соберите
      сборку с `adsEnabled=false`)
- [ ] Нет личных данных: номера телефона, реальных адресов, контактов
- [ ] Нет чужих товарных знаков и логотипов навигаторов
- [ ] Скорость на кадрах не пропагандирует превышение
- [ ] Иконка приложения на скриншотах совпадает с загружаемой иконкой
