## Подробное описание

```
Road Alert заранее предупреждает о камерах контроля скорости по GPS и локальной базе координат.

КАК ЭТО РАБОТАЕТ
Приложение сравнивает координаты вашего телефона с базой камер, которая хранится прямо на устройстве, и предупреждает голосом о камере впереди по ходу движения. Достаточно один раз настроить приложение и нажать «Начать поездку» — дальше можно заблокировать экран, предупреждения продолжат работать.

ЧТО УМЕЕТ
• Голосовые предупреждения о камере впереди
• Текущая скорость крупными цифрами
• Известное ограничение скорости и предупреждение о превышении
• Расстояние до камеры
• Работа при выключенном экране
• Полностью офлайн после загрузки базы
• Автоматическое обновление базы камер по Wi-Fi или мобильной сети
• Карта камер: где стоят камеры и какое на них ограничение скорости
• HUD-режим с зеркальным отображением для проекции на лобовое стекло
• Компактное предупреждение поверх навигатора (по желанию)
• Запуск поездки в одно нажатие при подключении к Bluetooth автомобиля
• Настройки: голос, звук, вибрация, допуск превышения, ранние или поздние предупреждения

ФИЛЬТРАЦИЯ ЛОЖНЫХ СРАБАТЫВАНИЙ
Приложение учитывает направление движения и направление камеры, поэтому не предупреждает о камерах на встречной полосе и, по возможности, о камерах на параллельных дорогах.

КОНФИДЕНЦИАЛЬНОСТЬ
Определение камер выполняется локально на устройстве. Приложение не ведёт историю поездок на сервере, не требует регистрации и не передаёт точные координаты рекламному SDK.

ИСТОЧНИК ДАННЫХ
База камер основана на открытых данных OpenStreetMap (© OpenStreetMap contributors, лицензия ODbL). База не является полной: часть камер может отсутствовать.

ВАЖНО
Это не радиоэлектронный радар-детектор. Приложение не принимает радарные сигналы, не глушит оборудование и не вмешивается в работу камер. Приложение является вспомогательным средством: соблюдайте ПДД и дорожные знаки, не взаимодействуйте с телефоном во время движения.
```

Карты и навигация / Авто

## Возрастная категория

Соответствует форме RuStore (приложение не содержит контента 18+).

## Контакты

- E-mail разработчика: ЗАПОЛНИТЬ реальным адресом (нужен и для подтверждения приложения в РСЯ)
- Политика конфиденциальности: ссылка на GitHub Pages (`site/privacy/index.html`)

## Чего в описании быть не должно

- «100% камер», «все камеры России»
- «радар-детектор», «ловит радары», «сигнал K/Ka»
- «лучший», «единственный», «официальный» без основания
- чужие товарные знаки и названия конкурентов
- функции, которых нет в сборке

## Скриншоты (минимум 3, до 10)

1. Главный экран до поездки
2. Активная поездка: скорость, ограничение, камера впереди
3. Карта камер с обозначениями ограничений скорости
4. HUD-режим
5. Настройки
6. (опционально) Overlay — только если на кадре нет интерфейса стороннего приложения

Требования: PNG/JPG, рекомендуется 16:9, до 2160×3840, файл ≤ 3 МБ,
реальные экраны приложения, без сторонней рекламы на кадрах.

## Иконка

512×512, строго 1:1, PNG/JPG, ≤ 1 МБ, фон заполнен целиком,
совпадает с иконкой установленного приложения, без чужих товарных знаков.
