# Что владелец делает руками

Claude Code сделал техническую часть. Ниже — действия, которые может выполнить
только владелец (юридически или физически). Порядок имеет значение.

## Этап 1. Прямо сейчас

1. Установить Android Studio (для отладки на телефоне и просмотра проекта).
   SDK для сборки уже установлен: `D:\Android\AndroidSdk` (см. `local.properties`).
2. Подключить Android-телефон, включить «Отладку по USB».
3. Установить debug-сборку:
   ```bash
   ./gradlew installDebug
   ```
4. Проехать тестовый маршрут и посмотреть, как ведут себя предупреждения.

## Этап 2. Перед первым релизом

5. Выбрать финальное название приложения (до 30 символов, без чужих брендов).
6. Выбрать уникальный `applicationId` — заменить `ru.example.roadalert`
   в `app/build.gradle.kts` (поля `namespace` и `applicationId`).
7. Создать release keystore:
   ```bash
   keytool -genkeypair -v -keystore road-alert-release.jks -alias road-alert -keyalg RSA -keysize 4096 -validity 10000
   ```
8. Сохранить `.jks`, alias и пароли минимум в двух безопасных местах.
   Потеря ключа = невозможность выпускать обновления.
9. Создать `keystore.properties` по образцу `keystore.properties.example`.
10. Репозиторий: `https://github.com/lisuner5945-stack/road-alert`. Включить GitHub Pages
    (Settings → Pages → Deploy from a branch → main → /docs).
    Адреса базы и политики уже прописаны в проекте.
11. Перечитать `legal/PRIVACY_POLICY_RU.md`, заменить все «ЗАПОЛНИТЬ»
    и указать реальный e-mail.

## Этап 3. RuStore

12. Создать аккаунт разработчика RuStore и пройти идентификацию.
13. Создать карточку приложения, взять тексты из `STORE_LISTING_RU.md`.
14. Загрузить APK или AAB (`./gradlew assembleRelease` / `bundleRelease`).
15. Заполнить декларацию разрешений по `PERMISSIONS_JUSTIFICATION_RU.md`.
16. Загрузить иконку 512×512 и минимум 3 скриншота реальных экранов.
17. Указать настоящий e-mail и ссылку на Privacy Policy.
18. Отправить на модерацию, ответить на замечания, опубликовать.

## Этап 4. РСЯ (реклама) — только после публикации

19. Создать Яндекс ID и аккаунт РСЯ, принять условия.
20. Добавить приложение, выбрав RuStore как магазин.
21. Подтвердить право на приложение (проще всего — по e-mail из карточки RuStore).
22. Пройти модерацию, создать production ad units.
23. Заполнить `ads.properties`:
    ```properties
    adsEnabled=true
    bannerUnitId=R-M-XXXXXXX-1
    interstitialUnitId=R-M-XXXXXXX-2
    ```
24. Собрать и загрузить обновление с рекламой.
25. Заполнить платёжный профиль и реквизиты, решить вопрос налогового статуса.

> Пока production-блоков нет, сборка работает на официальных demo-блоках Яндекса.
> Release-сборка с `demo-*` блоками не соберётся — это специально.
> Накручивать показы и клики по собственной рекламе запрещено правилами РСЯ.

## Чего Claude Code сделать не может

- пройти идентификацию и принять договоры от вашего имени;
- получить SMS/e-mail коды;
- заполнить банковские реквизиты и вывести деньги;
- проехать реальный маршрут и проверить ложные срабатывания.
