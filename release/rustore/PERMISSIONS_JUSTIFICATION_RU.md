# Обоснование разрешений для RuStore

Файл для заполнения декларации разрешений при публикации приложения.
Тексты можно копировать в форму RuStore как есть.

---

## ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION

> Используется во время активной поездки для определения текущего положения
> автомобиля, скорости и расстояния до камер контроля скорости. Основная
> обработка выполняется локально на устройстве, история поездок на сервер
> разработчика не передаётся. Геолокация запускается только после того, как
> пользователь сам нажал «Начать поездку», и прекращается при её завершении.

## FOREGROUND_SERVICE / FOREGROUND_SERVICE_LOCATION

> Приложение должно продолжать предупреждать водителя голосом при выключенном
> экране, поэтому во время поездки работает foreground service типа `location`
> с постоянным уведомлением и кнопкой остановки.

## POST_NOTIFICATIONS

> Используется для отображения уведомления активного foreground service
> (текущая скорость и расстояние до камеры) и уведомления «Автомобиль
> подключён — нажмите, чтобы запустить», если пользователь включил автозапуск.

## BLUETOOTH_CONNECT

> Запрашивается только при включении пользователем опционального запуска
> при подключении к выбранному Bluetooth-устройству автомобиля. Приложение
> не сканирует эфир постоянно: используется системный CompanionDeviceManager,
> который сам сообщает о появлении ранее выбранного устройства.

## SYSTEM_ALERT_WINDOW

> Запрашивается только при включении пользователем опции отображения
> компактного предупреждения поверх навигационного приложения. Карточка
> показывается лишь во время активной поездки при наличии камеры впереди,
> не содержит рекламы и не имитирует системный интерфейс.

## RECEIVE_BOOT_COMPLETED

> После перезагрузки устройства восстанавливается только расписание фоновой
> проверки обновлений базы камер. Определение геолокации после загрузки
> телефона не запускается.

## INTERNET / ACCESS_NETWORK_STATE

> Требуются для загрузки обновлений базы камер по HTTPS (не чаще раза в сутки),
> для подложки на экране «Карта камер» (тайлы OpenStreetMap) и для работы
> рекламного SDK. После загрузки базы предупреждения во время поездки работают
> полностью без интернета; карта — единственный экран, которому сеть нужна
> в момент открытия.

## REQUEST_COMPANION_RUN_IN_BACKGROUND / REQUEST_COMPANION_START_FOREGROUND_SERVICES_FROM_BACKGROUND

> Штатные companion-разрешения Android, необходимые для официального сценария
> запуска поездки при подключении к ранее выбранному автомобилю. Если система
> отказывает в автоматическом запуске, приложение показывает уведомление
> с запуском в одно нажатие.

## Разрешения, которые приложение НЕ запрашивает

- `ACCESS_BACKGROUND_LOCATION` — базовый сценарий его не требует.
- `READ_SMS`, `RECEIVE_SMS`, `READ_CONTACTS`, `READ_CALL_LOG`
- `RECORD_AUDIO`, `CAMERA`
- `QUERY_ALL_PACKAGES`, `MANAGE_EXTERNAL_STORAGE`, `REQUEST_INSTALL_PACKAGES`
- `BIND_ACCESSIBILITY_SERVICE`

Release-сборка автоматически проверяет отсутствие этих разрешений
(задача Gradle `verifyReleaseConfig`).
