# План проверки на реальных устройствах

Симулятор маршрута не заменяет реальную поездку (ТЗ §46, §51).

## Версии Android

Проверить минимум на: Android 12, 13, 14, 15, 16.
Обязательно на устройстве без Google Play Services, если такое доступно:
приложение не должно зависеть от GMS.

## Сценарии

| # | Что проверяем | Ожидаемый результат |
|---|---|---|
| 1 | Первый запуск | Онбординг понятен, диалогов разрешений до «Начать поездку» нет |
| 2 | Запрос геолокации | Диалог появляется при нажатии «Начать поездку» |
| 3 | Отказ в разрешении | Приложение не падает, показывает понятное сообщение |
| 4 | Старт/стоп поездки | Уведомление появляется и исчезает, кнопка «Остановить» работает |
| 5 | Экран выключен 10+ минут | Предупреждения продолжают звучать, сервис жив |
| 6 | Сторонний навигатор поверх | Голос слышен, overlay (если включён) виден |
| 7 | Overlay | Появляется только после выданного разрешения и только при камере впереди |
| 8 | Перетаскивание overlay | Позиция сохраняется после перезапуска поездки |
| 9 | Bluetooth-сценарий | Автозапуск или уведомление «нажмите, чтобы запустить» |
| 10 | Airplane mode | Предупреждения работают, приложение не падает |
| 11 | Возврат интернета | База обновляется, версия в настройках меняется |
| 12 | Обновление базы вручную | Кнопка в настройках возвращает понятный результат |
| 13 | Перезагрузка телефона | GPS сам не включается; расписание обновления восстановлено |
| 14 | Расход батареи | За час поездки расход сопоставим с обычным навигатором |
| 15 | TTS через Bluetooth авто | Голос слышен в динамиках машины |
| 16 | Нет русского голоса TTS | Приложение не падает, звуковой сигнал работает |

## Дорожная проверка

- [ ] Камера впереди — предупреждение приходит заранее и один раз на стадию
- [ ] Камера на встречной полосе — предупреждения нет
- [ ] Камера на параллельной дороге — ложных срабатываний нет или они единичны
- [ ] После проезда камеры повторного предупреждения нет
- [ ] Разворот и повторный проезд — предупреждение приходит снова
- [ ] Пропущенные камеры фиксируются (адрес/координаты) для доработки базы

## Замечания

Debug-сборка пишет технические события в logcat (тег `RoadAlert`):

```bash
adb logcat -s RoadAlert
```

События: `GPS_FIX_ACCEPTED`, `CAMERA_CANDIDATES`, `ALERT`, `DB_UPDATE_SUCCESS`, `AD_LOAD_FAILED`.
