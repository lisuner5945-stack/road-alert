1. Коротко

Приложение предупреждает водителя о камерах контроля скорости, сравнивая координаты GPS с базой камер, которая хранится на самом устройстве.

  • маршруты и история поездок не передаются разработчику;
  • аккаунтов, регистрации и пользовательского сервера нет;
  • точная геолокация не передаётся рекламному SDK кодом приложения;
  • обработка координат выполняется локально и только во время активной поездки.

2. Геолокация

Точные координаты нужны, чтобы рассчитать расстояние до камеры впереди, скорость и направление движения. Определение координат начинается только после того, как пользователь сам нажал «Начать поездку», и прекращается при её завершении. Постоянный GPS-трек не сохраняется и не отправляется разработчику.

3. Настройки

Локально хранятся параметры предупреждений, выбранное Bluetooth-устройство автомобиля, позиция overlay, версия базы камер и время последней проверки обновления. Эти данные не покидают устройство.

4. Обновление базы камер

Приложение не чаще раза в сутки и только при наличии сети скачивает файл базы по HTTPS. Передаются лишь технические данные, неизбежные при HTTP-запросе (например, IP-адрес). Геолокация в этом запросе не участвует.

5. Карта камер

На экране «Карта камер» подложка загружается с публичных серверов OpenStreetMap. Серверу карты становится известен номер рассматриваемого квадрата карты, то есть примерная область просмотра — но не маршрут и не точные координаты устройства. Отметка «где я» рисуется на самом устройстве, координаты никуда не отправляются. Тайлы кэшируются во внутреннем кэше приложения (не более 60 МБ).

6. Реклама

Приложение может показывать рекламу через Yandex Mobile Ads SDK. SDK может самостоятельно обрабатывать технические и рекламные идентификаторы согласно правилам Яндекса. Приложение не передаёт SDK точные GPS-координаты; отслеживание местоположения в SDK выключено явно. Полноэкранная реклама никогда не показывается во время активной поездки.

7. Что не собирается

Контакты, SMS, журнал звонков, микрофон, камера, фотографии, IMEI, номер телефона, платёжные данные — не запрашиваются и не обрабатываются.

10. Как остановить обработку данных

Завершить поездку кнопкой «Стоп», отозвать разрешение на геолокацию в настройках Android или удалить приложение — все локальные данные удаляются вместе с ним.
